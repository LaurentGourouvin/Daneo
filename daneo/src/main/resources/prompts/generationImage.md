Create an educational illustration for a vocabulary flashcard in the mobile learning application **Daneo**.

Part of speech:

The Korean word is provided only to help understand the vocabulary context.

**DO NOT render the Korean word anywhere in the image.**

## Purpose

The illustration exists exclusively to create an immediate visual association with the vocabulary concept.

The learner should understand what the image represents in less than one second, even when the image is displayed at approximately **400 × 400 px on a smartphone**.

This is an educational flashcard illustration.

It is not:

- a poster;
- an advertisement;
- a wallpaper;
- a book cover;
- an infographic.

Prioritize **clarity and memorability over artistic complexity**.

## Visual style

Use a consistent **modern manga / comic-book inspired illustration style**.

The style should be:

- clean;
- polished;
- warm;
- modern;
- slightly playful;
- adult-friendly;
- expressive without exaggeration;
- simple;
- visually memorable;
- suitable for a language-learning application.

Use:

- clean line art;
- soft outlines;
- simple shapes;
- controlled detail;
- soft shading;
- a pleasant and slightly muted color palette;
- subtle manga / comic visual influence.

Do NOT use:

- photorealism;
- hyperrealism;
- extremely detailed manga rendering;
- childish cartoon styling;
- chibi proportions;
- dramatic cinematic lighting;
- complex scenery;
- excessive visual effects.

The objective is to maintain a **consistent illustration system across thousands of vocabulary flashcards**.

## Composition

Use a **square composition**.

The main concept must:

- be centered or clearly dominant;
- occupy a large part of the image;
- remain clearly recognizable at small size.

Prefer:

- one primary subject;
- close or medium framing;
- generous negative space;
- a simple background;
- minimal secondary objects.

Secondary elements may only be included when they are necessary to understand the meaning.

Avoid:

- clutter;
- complex environments;
- crowds;
- unnecessary objects;
- tiny details;
- decorative elements unrelated to the vocabulary.

## Absolute text rule

The generated image must contain **ZERO TEXT**.

Do not generate:

- French words;
- Korean words;
- Hangul;
- romanization;
- Latin letters;
- numbers;
- labels;
- captions;
- speech bubbles;
- thought bubbles containing text;
- signs containing text;
- logos;
- interface elements;
- watermarks;
- written symbols used as decoration.

If the scene naturally contains an object that normally displays writing, such as:

- a book;
- a newspaper;
- a smartphone;
- a computer;
- a road sign;
- a shop;
- packaging;
- clothing;

keep that surface completely blank or use non-textual abstract shapes.

**The image itself must communicate the meaning without using written language.**

All vocabulary text will be rendered separately by the Daneo application interface.

## Representation rules

### Concrete nouns

Represent the object, animal, food, person or concept directly.

Example:

`pomme / 사과`

→ show one clearly recognizable apple as the dominant subject.

### Animals

Show the animal clearly with a simple pose that makes identification immediate.

### Food

Show the food itself clearly.

Avoid complex restaurant scenes unless needed to identify the concept.

### Places

Create a simple iconic visual representation of the place or type of place.

### People and professions

Show a person performing an activity or using visual contextual elements that make the profession understandable.

Avoid stereotypes.

### Verbs

Represent the action through one simple, immediately understandable scene.

The action must be visually dominant.

### Adjectives

Represent the property through a simple subject or situation where the characteristic is visually obvious.

### Abstract concepts

Only use a visual metaphor when the association is intuitive and immediately understandable.

Do not create a complicated symbolic composition merely to force an illustration.

## Cultural direction

Daneo teaches Korean, but the illustration does not need to contain stereotypical Korean cultural elements.

Do not automatically add:

- Korean flags;
- Seoul landmarks;
- hanbok;
- temples;
- K-pop references;
- Korean food;
- Korean text.

Use Korean cultural context only when it is genuinely relevant to the vocabulary concept.

## Consistency requirement

All Daneo illustrations should feel as if they belong to the same visual collection.

Maintain consistent:

- line weight;
- detail level;
- shading style;
- visual density;
- framing;
- color softness;
- manga/comic influence.

A card showing an apple and another showing a cat should visibly belong to the same application.

## Final instruction

Generate **one clear educational illustration representing only the intended meaning of `{{frenchWord}}` (`{{meaning}}`)**.

The image must be instantly recognizable on a mobile flashcard.

**Do not include any text whatsoever in the generated image.**
